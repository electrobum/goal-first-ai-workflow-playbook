# Examples

These examples are intentionally small.

They are not full systems. They are reference snapshots showing what the control surface looks like in real use.

## Included examples

### [docs-refresh](docs-refresh/README.md)

Use this example if your workflow is updating documentation, knowledge bases, internal guides, or release notes.

Highlights:

- exact next-file handoff;
- validator tied to real documentation quality;
- compact truth surface for a non-code workflow.

### [regression-bugfix](regression-bugfix/README.md)

Use this example if your workflow is debugging, patching, and validating software changes across sessions.

Highlights:

- focused regression target;
- validator tied to real test closure;
- continuation note that points to the exact file and failure mode.

## How to use these examples

Do not copy them blindly.

Instead:

1. choose the example closest to your workflow;
2. copy the structure, not the wording;
3. replace the sample task with your own real task;
4. make your validator stricter than your status updates.
