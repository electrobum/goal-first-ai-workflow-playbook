# Contributing

Thanks for helping improve this playbook.

## What contributions fit best

- clearer explanations of long-haul AI workflow design;
- better examples of truthful validation and exact continuation;
- reusable templates that stay generic across use cases;
- corrections that reduce hype and increase operational clarity;
- examples showing how to avoid fake progress in real projects.

## What to avoid

- domain-private data dumps;
- marketing-heavy claims about full autonomy;
- templates that assume one tool vendor or one narrow domain;
- control surfaces that optimize for activity signals instead of evidence.

## Pull request expectations

Please keep changes:

- concise;
- battle-tested in tone;
- honest about tradeoffs;
- focused on reusable patterns rather than private context.

If you add a new template or example, explain:

- what problem it solves;
- what fake-progress failure it guards against;
- what evidence would prove it is working.
