# Hard Gates Over Heartbeats

Freshness is not progress.

Useful systems separate:

- a process is alive;
- a process produced evidence.

Hard gates should fail when progress is fake, thin, or unverified. That usually means checking for things like:

- real rows rather than header-only tables;
- required labels that closed instead of remaining blank;
- repaired links rather than narrative claims;
- traceable output files rather than fresh status text.

Heartbeats and timestamps are still useful, but only as support signals.
