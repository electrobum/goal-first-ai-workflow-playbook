# Repository Positioning

## Recommended public name

`goal-first-ai-workflow-playbook`

## Recommended subtitle

Design patterns for long-running AI workflows that keep making real progress.

## Recommended framing

Lead with:

- long-haul AI workflow engineering lessons;
- Goal-first workflow design;
- practical anti-fake-progress controls;
- file-backed continuity for real work.

Avoid centering:

- magical multi-agent AGI claims;
- universal self-driving work claims;
- internal project history as the main product.

## Suggested GitHub description

Practical patterns, templates, and examples for AI workflows that need exact continuation, hard gates, and low-theater execution.

## Recommended tone

The strongest public tone for this repository is:

- practical;
- honest;
- battle-tested;
- anti-hype;
- generous with reusable structure.
